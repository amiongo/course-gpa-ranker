# ZJU Course GPA Ranker (浙江大学选课辅助数据库与均绩排行系统)

[![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2010%2F11-lightgrey.svg)](https://microsoft.com)
[![Zero Dependency](https://img.shields.io/badge/Dependencies-Zero%20Runtime%20Deps-brightgreen.svg)](https://docs.python.org/3/library/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

专为**浙江大学 (ZJU)** 本科生打造的本地化选课决策辅助数据库与课程历史均绩 (GPA) 查询系统。

通过对浙江大学历史选课数据、开课学院及教师历史评分样本进行结构化清洗与离线索引，本项目提供了直观的课程均绩多维排行、空闲课表时间段冲突过滤、培养方案层级分类树以及多课程批量横向对比等功能，帮助浙大学子科学制定选课策略。

---

## 🌟 核心功能特性

### 1. 课程均绩全景排行与教师评定
- **智能模糊搜索**：输入课程名称或教师姓名，秒级匹配课程所有历史开课教学班。
- **多维度评分指标**：展示每位任课老师的历史平均 GPA、最高/最低绩点、成绩标准差以及评价样本数量。
- **样本量过滤**：支持自定义最低样本量门槛（如 `>=30`、`>=50`），过滤因选课人数过少而产生的极端离群值。

### 2. 交互式空闲课表严格子集匹配
- 提供周一至周日、每天第 1~13 节的可视化课程表网格。
- 支持直接在课表矩阵上勾选你的**空闲时段**（Free Slots）。
- 后端采用**严格子集约束算法**（`class_slots ⊆ user_free_slots`），排查任何上课冲突，仅保留**所有节次均落在所选空闲时段内**的课程与教学班。

### 3. 四级培养方案课程分类树
- 参照浙江大学本科生培养方案，建立清晰的双层分类导航体系：
  - **通识课程**：思政理论类、军体素养类、大学外语类、计算与信息素养类、通识核心与选修类
  - **大类基础课程**：数理基础类、化学与生化类、工程技术基础类、人文社科基础类、农医地环基础类
  - **专业课程**：计算机与人工智能类、电子信息与通信电气类、机械动力与航空航天类、材料土木与化工建筑类、经济金融与商科管理类、人文历史与哲学法学类等
  - **实践与创新课程**：专业实验与实践实习、课程设计与综合研讨、科研训练与创新创业、毕业设计等

### 4. 学分智能推断与关键词正反向过滤
- 根据全校开课特征规则库，自动推断课程对应学分（如普通物理、微积分、通识选修、体育等）。
- **排除关键词过滤**：支持指定排除词（如排除“乙”、“丙”、“实验”），精准分离不同难度层级或类型的同名系列课程。

### 5. 批量选课均绩对比
- 支持在输入框中逐行粘贴多门意向课程名称，一键生成横向对比榜单，按各课程的最高均绩或平均均绩降序排列。

### 6. 零运行时依赖与极速体验
- **零三方依赖**：服务端基于纯 Python 3.10+ 标准库（`http.server`、`json`、`csv`）实现，无需安装 Flask、Django、FastAPI 等重型框架。
- **原生现代前端**：采用原生 HTML5、CSS3 与纯 ES6 JavaScript 构建，界面轻量流畅，无前端打包构建负担。
- **安全与离线**：全部数据存储于本地 `data/` 目录，服务默认仅监听本机回环地址 `127.0.0.1:8765`，断网可用，杜绝隐私泄漏。

## 🚀 快速上手

### 运行环境
- 操作系统：Windows 10 / 11（macOS / Linux 亦可正常运行源码）
- Python 版本：Python 3.10 或更新版本

### 方式一：源码直接运行（推荐）

1. **一键启动**：
   双击根目录下的 `run.bat`，脚本会自动检测 Python 环境并在后台启动本地服务。
2. 启动后，系统默认浏览器会自动打开并跳转至：
   ```
   http://127.0.0.1:8765
   ```
3. **命令行启动方式**：
   ```bash
   python app.py
   ```
   *可选参数：*
   - `--port 8765`：指定本地监听端口（若端口被占用会自动递增寻找可用端口）。
   - `--no-browser`：启动服务后不自动调起系统浏览器。
   - `--keep-running`：关闭网页标签后保持服务常驻后台（默认检测到前端无连接数秒后自动退出）。

### 方式二：打包为 Windows 独立免安装版 (.exe)

如果你需要分享给未安装 Python 环境的同学，可以使用 PyInstaller 打包为单文件免安装绿色版：

1. 安装打包工具：
   ```bash
   pip install -r requirements-build.txt
   ```
2. 执行打包脚本：
   ```cmd
   build_windows.bat
   ```
3. 构建完成后，将在 `release/` 目录下生成 `course-gpa-ranker-v2.exe`，该文件已完整嵌入 `web/`、`data/` 以及 Python 运行时，直接双击即可运行。

## 🔌 API 接口概览

本地后端提供了一组纯 JSON 格式的轻量级 RESTful API：

| 接口端点 | 方法 | 说明 |
| :--- | :--- | :--- |
| `/api/categories` | `GET` | 获取培养方案四级分类树结构及各分类课程总数统计 |
| `/api/courses` | `POST` | 多维综合筛选（支持分类、关键词、排除词、空闲课表时段、最低样本量与分页） |
| `/api/course/<name>` | `GET` | 查询指定课程详细均绩分布与各任课老师详情 |
| `/api/rank` | `POST` | 单门或多门课程综合评分计算 |
| `/api/search` | `GET` | 课程名称与教师姓名即时联想补全 |
